Version 1.3.4 · what's new

Before you start

  1. Use Chrome or Edge on a computer. Installing needs Web Serial, which phones and other browsers don't have.
  2. Close any program that uses the board's port, then connect the board to this computer with its USB cable.
  3. Pick your board below, press Install and choose the board's port.

Install

FYSETC E4

The OAPA board, with TMC2209 drivers.

This browser cannot install firmware. Use Chrome or Edge on a computer. Open this page over https.

ESP32 with STEP/DIR drivers

Any ESP32 with plain drivers (A4988, DRV8825, LV8729…).

This browser cannot install firmware. Use Chrome or Edge on a computer. Open this page over https.

Good to know

  1. Updating keeps the board's settings (WiFi, update password, calibration). If the installer asks whether to erase the device, answer no for an update.
  2. Coming from firmware 1.2.x, or if the board misbehaves after an update, answer yes: the board starts with factory settings.
  3. A board on WiFi can also be updated from its own web page, without a cable.
